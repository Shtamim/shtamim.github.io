## ◈ About

A personal digital space documenting my journey through engineering, software development, cybersecurity, robotics, and technology.

This repository contains the source code of my portfolio website — a place to showcase my work, experiments, interests, and ongoing exploration.

## ◈ Development

Clone the repository and run it locally.

```bash
git clone https://github.com/Shtamim/shtamim.github.io.git

cd shtamim.github.io
```
